## 🎮 What This Mod Does

ETS2-ATS-DLAA-DLSS-Injection-Mod is an unofficial fan mod for Euro Truck Simulator 2 and American Truck Simulator. It adds NVIDIA DLAA and DLSS upscaling support to the games, both in flat-screen play and in VR. The project is designed for players who want cleaner anti-aliasing, smoother image quality, and the option to use DLSS upscaling while driving.

DLAA is an anti-aliasing mode that focuses on image quality. It helps reduce jagged edges and shimmering on road markings, guardrails, power lines, trees, and distant scenery. DLSS is an upscaling feature that can help performance by rendering at a lower internal resolution and then rebuilding the image to your chosen output size. For ETS2 and ATS players, this can mean a sharper-looking picture or a better balance between visual quality and smoothness.

The mod uses a dinput8.dll injector. In simple terms, this is a file that loads the mod when the game starts. You do not need to write code or use developer tools. The project page provides the files and current setup guidance for the application. The mod is tagged for DirectX 11, NVIDIA DLAA, NVIDIA DLSS, VR, OpenXR, HDR, and SCS Software truck simulators.

This is a community project. It is not an official SCS Software release and it is not an official NVIDIA product. It is built for players who want to experiment with modern anti-aliasing and upscaling options in ETS2 and ATS.
